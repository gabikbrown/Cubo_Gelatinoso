# Criatura lendária: Cubo Gelatinoso

**Autora:** Gabriela O. de Lima Cabral\
**Professor:** Daniel Roberto Cassar\
**Ilum - Escola de ciência**\
**Centro Nacional de Pesquisa em Energia e Materiais (CNPEM)**


Este trabalho procura, através de exames cotidianos (como colesterol e pressão), determinar as chances de um novo paciente ter ou não a Doença Arterial Coronária (DAC), que é o resultado da obstrução das artérias coronárias. 

Como exames de rotina são bastantes comuns de serem feitos entre a maioria das pessoas. Enquanto os exames apenas para detecção da DAC além de serem bastante específicos, então muitas pessoas não realizam, são também caros.
